# Web Bán Quần Áo

Web bán hàng với React + Vite, Tailwind CSS, Flask, PostgreSQL + pgvector

## Yêu cầu
- Docker & Docker Compose
- Git

## Cài đặt và chạy

1. Clone repository:
```bash
git clone https://github.com/MinhTris2204/webbanquanao.git
cd webbanquanao
```

2. Chạy với Docker:
```bash
docker-compose up --build
```

3. Truy cập:
- Frontend: http://localhost:5173
- Backend API: http://localhost:5000
