=== CHẠY MIGRATION MỚI ===
Sau khi pull code mới, chạy migration để thêm cột ghichu vào bảng orders:

cd backend
flask db upgrade

Hoặc nếu dùng Docker:
docker-compose exec backend flask db upgrade
